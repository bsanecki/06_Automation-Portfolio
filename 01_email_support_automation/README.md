# 📧 Email Support Automation

Automated email support workflow built with **Activepieces**.

## Workflow

`Microsoft Outlook → Router → Reply to Email → Code → Discord`

## Features

- Detects new incoming emails
- Filters selected automated/system emails
- Sends an automatic acknowledgement
- Extracts sender name, email and subject
- Sends a formatted Discord notification
- Uses Discord Embeds for clear notifications

## Technologies

- Activepieces
- Microsoft Outlook
- Discord Webhooks
- JavaScript
- JSON

## Result

The workflow was tested successfully and runs automatically without manual intervention.
